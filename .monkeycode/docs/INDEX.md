# 慢慢长大

温柔视觉与真实时间成本相结合的浏览器养成小游戏。首次从小猫橘汐、小狗麦芽、宝宝阿团、小植物团子四个对象中选择一个并为它起名（最多 12 字，留空沿用默认名），名字贯穿界面、引擎日志与养育日记，持续照护与成长。

## 启动
```bash
python3 -m http.server 8000 --directory /workspace
```

入口为 index.html；规则引擎为 engine.js；界面逻辑为 game.js；插画为 visuals.js；背景音乐为 audio.js（Web Audio 本地合成音景，零外部音频文件）；样式为 style.css 与 enhancements.css。运行应用无需安装依赖。

美术资产位于 assets/：bg-{type}.jpg 为四间手绘房间背景，stages/{type}-{1..4}.png 为阶段抠图立绘，acc/{type}-{n}.png 为饰物抠图；来源为设计工具导出的角色设定集，重生成管线见 tools/prepare_assets.py（rembg 抠图 + 缩放，需在解压设计包后运行）。

存档保存在当前浏览器 localStorage（v2 含 worn 穿戴饰物与 health/status/criticalAt/leftAt 健康字段），支持第一版迁移、导出和导入。提醒仅在应用内生效。照护保持页面可见即可计时，切后台暂停；成长使用现实 1 天对应游戏 30 天的压缩日历。夜间节奏（默认开启，22 点至次日 6 点，设置页可调整或关闭）：就寝时段内需求衰减与健康度流失按半速结算，病危 24 小时宽限倒计时同步减半（实际可延长至约 32–40 小时），照护动作、任务计时、恢复速率（全需求 ≥30 时 +1/h）与成长经验照常。物资类照护支持一次取用多份（弹窗内库存卡片点选 + 份数步进器，耗时与效果按份数等比增加，上限受库存、需求余量与 10 份封顶约束）；免费类照护（安抚休息、徒手互动）固定一份。照护弹窗内展示本次预计恢复量（含需求封顶提示）。主页健康工具箱：持有医疗用品或角色虚弱时显示，可直接使用医疗用品，无货时一键跳转小铺医疗页签。生活小铺含 16 件随身饰物（积分兑换、按阶段解锁、可穿戴）与医疗照护类商品（安心药箱、回春灵药）。

健康系统：需求长期低于 10 时健康度按每项 -0.75/真实小时流失（上限 3/h），全部需求 ≥30 时 +1/h 回复，每次有效照护 +2；分级为萎靡（<70）、生病（<40，成长经验减半、房间生病角标）、病重（<20，禁触摸与玩耍，主页出现虚弱风险横幅）。健康度归零进入 24 真实小时病危宽限期（横幅显示倒计时），可用回春灵药复活或经持续照护自然回升至 20 解除。回春灵药为强效医疗（恢复 60 健康度），健康度低于 70 的任何虚弱状态或病危窗口均可使用；安心药箱为轻度医疗（恢复 40 健康度），健康度低于 70 可用。主页亲密度卡片下方有健康工具箱：持有医疗用品或角色虚弱时显示，可直接使用医疗用品（无需去小铺），无货时一键跳转小铺医疗页签。超时角色按类型叙事永久离开（baby 被家人接走 / cat·dog 出门远行 / plant 化作春泥），留念面板展示陪伴履历后可重新领养。旧 v2 存档自动补健康默认值。

## 验证
```bash
node --test engine.test.cjs visuals.test.cjs audio.test.cjs
node browser.test.cjs
```

浏览器测试依赖全局安装的 @playwright/test、Chromium 及对应 Linux 系统库。当前测试使用 channel chromium，可使用完整 Chromium 包，无需 headless-shell。浏览器测试覆盖 375、768、1440 像素宽度。
