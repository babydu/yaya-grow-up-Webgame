# 慢慢长大

## 产品目标
通过重复、有真实时间成本的照护体验，感受养育责任。第一版为手机和桌面均可使用的浏览器应用。

## 验收要求
1. 当用户选择小猫、小狗或宝宝时，系统应加载该角色独立的状态和记录。
2. 当用户按住照护按钮时，系统应累计前台有效操作时间；当用户松手、窗口失焦或页面隐藏时，系统应暂停累计。
3. 喂奶任务应要求累计 300 秒有效照护时间；清洁、陪伴和哄睡分别要求 30、60、120 秒。
4. 当完成照护时，系统应更新对应需求、成长进度、陪伴统计和养育日记。
5. 当用户离线后返回时，系统应按真实经过时间降低需求，数值保持在 0 至 100。
6. 当用户刷新页面时，系统应恢复角色、照护任务进度和记录。
7. 当存储不可用时，系统应显示提示并允许本次会话继续。
8. 成长每获得 100 经验提升一个阶段，阶段包含幼年、探索、成长、成年。应用应说明游戏模拟与专业养育建议的边界。
