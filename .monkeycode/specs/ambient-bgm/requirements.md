# 氛围背景音乐

## 介绍

为照护操作与日常陪伴提供可选的背景音景（白噪音、雨声、海浪、八音盒轻音乐等）。全部声音由浏览器 Web Audio API 实时本地合成，不引用任何外部音频文件，从根源上规避版权问题。用户可在偏好设置中开启或关闭背景音乐、自选风格。

## 术语

- **音景**：一种持续的背景声氛围，如雨声、海浪、白噪音或轻音乐。
- **Web Audio 合成**：用浏览器内置 AudioContext 以振荡器、噪声缓冲与滤波器实时生成声音。
- **播放条件**：背景音乐已开启，且触发场景处于活跃状态（如照护任务进行中）。

## 需求

### 音乐开关与偏好

1. 当用户在偏好设置开启背景音乐时，系统应在下一次满足播放条件时开始播放当前风格音景。
2. 当用户在偏好设置关闭背景音乐时，系统应立即停止播放。
3. 系统应将开关状态、风格与音量保存在浏览器本地存储，下次打开时自动恢复。

### 风格选择

4. 系统应内置至少五种本地合成音景：白噪音、雨声、海浪、八音盒轻音乐、森林晨间。
5. 当用户切换风格且正在播放时，系统应在一秒内淡出旧音景并淡入新音景。
6. 系统应使用浏览器实时合成生成全部声音，保持零外部音频文件依赖。

### 播放时机

7. 当照护任务进行时（用户点击开始且照护页面可见），若背景音乐已开启，系统应播放当前音景。
8. 当照护暂停（切换标签页、锁屏或关闭弹窗）或照护完成时，系统应淡出并停止音景。

### 音量

9. 系统应提供音量滑块，调节范围为零至默认音量上限，默认音量为舒适偏低的水平。

### 边界与降级

10. 当浏览器自动播放策略阻止音频启动时，系统应在用户下一次交互时恢复播放，并保持开关状态不变。
11. 当音频合成或播放失败时，系统应静默降级为无声状态，页面其余功能保持可用。
12. 当用户修改音量时，系统应即时生效并同步到本地存储。
