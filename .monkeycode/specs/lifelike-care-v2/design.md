# 阶段化养育技术设计

## 分层
- engine.js：无外部依赖的确定性状态转换，浏览器全局及 CommonJS 双入口。
- game.js：对象选择、计时、页面、商城、存档和事件处理。
- visuals.js：延用第一版图标和小屋插画，封装作用域防止全局变量冲突。
- enhancements.css：新增界面样式，延用第一版视觉语言。

## 存档
localStorage 的 slow-growing-v2 保存单对象状态。支持从 slow-growing-v1 迁移选中的对象；旧版本数据保留。任务包含动作、商品、固定总时长和累计秒数。开始时扣库存，恢复保持幂等。

## 时间
performance.now 计算前台增量，250 毫秒更新一次，限制单次计时跳跃为 1 秒，后台隐藏立即暂停。每两秒保存进行中的任务。恢复需要用户明确点击继续。

## 成长与经济
游戏年龄门槛为 0、30、180、360 天，经验门槛为 0、100、300、600。喂养时长为 5、4、3、2 分钟，关注间隔为 3、4、5、6 小时。宝宝最终阶段为幼儿期，猫狗最终阶段为成年期。

衰减按 refresh 结束时的阶段计算整个间隔；采用游戏化近似。营养商品为包含完整主食的组合。宝宝辅食阶段仍可选择配方奶。商城为虚拟积分经济，无实际付款。

## 测试
node --test engine.test.cjs 执行规则测试。browser.test.cjs 用 Chromium 验证实际页面选择、签到、暂停恢复、物资与响应式布局。旧 app.js 和 test.cjs 保留作为第一版参考，入口已使用新模块。
